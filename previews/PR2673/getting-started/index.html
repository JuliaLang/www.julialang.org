Getting started

Pick a starter kit

The General registry holds over 12,000 packages. To begin, you need about five. Below are the ones people reach for first, grouped by what you're here to do. Every kit is one line to install.

No Julia yet? Install it first; it takes a minute. New to the language? Read what Julia is, or start with the manual.

julia> ]
(@v1.13) pkg> add CSV DataFrames DataFramesMeta
  1. 1
    Press ] at the julia> prompt. It turns blue: you're in package mode.
  2. 2
    Paste a kit's add line. Julia fetches the packages and precompiles them.
  3. 3
    Press Backspace to leave, then using them. If you forget step 2, using offers to install for you.

Pack these first: the toolbelt

Whatever you end up doing, these make every session better. Choose the ones you want, and we'll write your startup.jl so they load each time you start Julia.

1. Install them into your default environment

pkg> add DocBrowser Revise OhMyREPL

2. Save this as ~/.julia/config/startup.jl

if isinteractive()
    using Revise
    using DocBrowser
    using OhMyREPL
end

On Windows the file lives at %USERPROFILE%\.julia\config\startup.jl. Revise always goes first, so it can track everything loaded after it.

What are you here to do?

Pick the one that sounds most like you, or browse everything. Each kit lists the packages to start with, and a few to try next.

🧮

Wrangle data

You have a CSV and some questions.

  • CSV.jl Fast, forgiving reader and writer for delimited files.
  • DataFrames.jl Tables you can filter, join, group and reshape.
  • DataFramesMeta.jl Readable pipelines with @chain, @subset and @combine.
pkg> add CSV DataFrames DataFramesMeta

Next: TidierData.jl (for dplyr fans) · XLSX.jl · Arrow.jl · DuckDB.jl · JSON.jl

Taste it 
using CSV, DataFrames, DataFramesMeta, Statistics

df = CSV.read("penguins.csv", DataFrame)

@chain df begin
    dropmissing(:body_mass_g)
    groupby(:species)
    @combine(:mean_mass = mean(:body_mass_g))
end

Make a picture

Numbers are fine, but you want to see them.

  • CairoMakie.jl Publication-quality 2D and 3D plots, from the Makie family.
  • AlgebraOfGraphics.jl Grammar-of-graphics plotting straight from a table.
  • Plots.jl The other big family: one quick syntax, many backends.
pkg> add CairoMakie AlgebraOfGraphics Plots

Next: GLMakie.jl (interactive windows) · WGLMakie.jl (in the browser) · UnicodePlots.jl (in the terminal!)

Taste it 
using CairoMakie

x = range(0, 4π, length = 200)
fig, ax, _ = lines(x, sin.(x); label = "sin")
lines!(ax, x, cos.(x); label = "cos")
axislegend(ax)
save("waves.png", fig)
📓

Think in notebooks

You want code, prose and plots on one page.

  • Pluto.jl Reactive notebooks: change one cell and everything that depends on it updates.
  • PlutoUI.jl Sliders, buttons and pickers wired straight into your variables.
  • IJulia.jl The Julia kernel for Jupyter and JupyterLab.
pkg> add Pluto PlutoUI IJulia

Next: Quarto (reports and slides) · Literate.jl (scripts that become docs)

Taste it 
using Pluto
Pluto.run()   # opens a notebook in your browser

# then, in a cell:
using PlutoUI
@bind n Slider(1:100)
🌀

Simulate the world

Differential equations, physical models, things that change over time.

  • DifferentialEquations.jl Hundreds of solvers for ODEs, SDEs, DAEs and more.
  • ModelingToolkit.jl Write models symbolically; it simplifies and generates fast code.
  • Unitful.jl Physical units that check your dimensions and cost nothing at run time.
pkg> add DifferentialEquations ModelingToolkit Unitful

Next: Measurements.jl (error propagation) · Agents.jl (agent-based models) · all of SciML

Taste it 
using DifferentialEquations, Plots

decay(u, p, t) = -p * u
prob = ODEProblem(decay, 1.0, (0.0, 5.0), 0.8)
sol = solve(prob)
plot(sol)
🎯

Find the best answer

Schedules, portfolios, fits, designs: anything with a "minimize" in it.

  • JuMP.jl Write optimization models the way they look on paper.
  • HiGHS.jl A fast open-source solver for linear and mixed-integer problems.
  • Optim.jl Minimize any Julia function, with or without gradients.
pkg> add JuMP HiGHS Optim

Next: Ipopt.jl (nonlinear) · Optimization.jl · Roots.jl

Taste it 
using JuMP, HiGHS

model = Model(HiGHS.Optimizer)
@variable(model, x >= 0)
@variable(model, 0 <= y <= 3)
@objective(model, Max, 12x + 20y)
@constraint(model, 6x + 8y <= 100)
@constraint(model, 7x + 12y <= 120)
optimize!(model)
value(x), value(y)
🧠

Teach a machine

Neural networks, classic models, and gradients of anything.

  • Flux.jl Deep learning that is plain Julia all the way down.
  • MLJ.jl One interface to 200+ models: trees, boosting, clustering, tuning.
  • Enzyme.jl Automatic differentiation at the compiler level.
pkg> add Flux MLJ Enzyme

Next: Lux.jl (explicit-parameter networks) · ForwardDiff.jl · MLDatasets.jl

Taste it 
using Flux

model = Chain(Dense(4 => 16, relu), Dense(16 => 3), softmax)
opt = Flux.setup(Adam(), model)
loss(m, x, y) = Flux.crossentropy(m(x), y)

# x: 4×N features, y: 3×N one-hot labels
Flux.train!(loss, model, [(x, y)], opt)
🎲

Do the statistics

Distributions, regressions, tests, and Bayesian models.

  • Distributions.jl Sample, fit and evaluate nearly every probability distribution.
  • GLM.jl Linear and generalized linear models with R-style @formulas.
  • Turing.jl Probabilistic programming: write the model, get the posterior.
pkg> add Distributions GLM Turing

Next: StatsBase.jl · HypothesisTests.jl · MixedModels.jl

Taste it 
using Turing

@model function coin(flips)
    p ~ Beta(1, 1)
    for i in eachindex(flips)
        flips[i] ~ Bernoulli(p)
    end
end

chain = sample(coin([1, 0, 1, 1, 1, 0, 1]), NUTS(), 1000)

Go faster

Your code works. Now you want all the cores, or a GPU.

  • OhMyThreads.jl Multithreaded map, reduce and loops without the footguns.
  • StaticArrays.jl Small fixed-size arrays that live on the stack.
  • CUDA.jl Run arrays and your own kernels on NVIDIA GPUs.
pkg> add OhMyThreads StaticArrays CUDA

Next: AMDGPU.jl · Metal.jl · KernelAbstractions.jl · JET.jl · Cthulhu.jl

Taste it 
# start Julia with: julia -t auto
using OhMyThreads, BenchmarkTools

@btime sum(x -> sin(x)^2, 1:10^7)
@btime tmapreduce(x -> sin(x)^2, +, 1:10^7)

Bring your old friends

You have Python, R or C++ code you're not ready to leave behind.

  • PythonCall.jl Call any Python library from Julia, and Julia from Python.
  • RCall.jl Use R and its packages, with an R prompt inside the REPL.
  • CxxWrap.jl Wrap C++ libraries. (C and Fortran need nothing: just @ccall.)
pkg> add PythonCall RCall CxxWrap

Next: CondaPkg.jl (Python dependencies) · MATLAB.jl · Noteworthy differences

Taste it 
using PythonCall, CondaPkg
CondaPkg.add("numpy")

np = pyimport("numpy")
np.linspace(0, 1, 5)

Build for the web

APIs, dashboards, and talking to other services.

  • HTTP.jl HTTP clients and servers, plus WebSockets.
  • JSON.jl Read and write JSON, straight into your own types.
  • Oxygen.jl A small web framework: routes in a few lines.
pkg> add HTTP JSON Oxygen

Next: Genie.jl (full-stack apps) · Bonito.jl (interactive dashboards)

Taste it 
using Oxygen

@get "/hello/{name}" function (req, name)
    "Hello, $name!"
end

serve(port = 8080)   # visit localhost:8080/hello/julia

Look at pixels and signals

Photos, microscopy, audio, sensor data.

  • Images.jl Filter, segment, resize and measure images as plain arrays.
  • FileIO.jl One load and save for images, audio, meshes and more.
  • FFTW.jl Fast Fourier transforms, from the library everyone uses.
pkg> add Images FileIO FFTW

Next: DSP.jl (filters, spectrograms) · Colors.jl

Taste it 
using Images, FileIO

img = load("cat.png")
small = imresize(Gray.(img); ratio = 0.5)
save("cat-gray.png", small)

Code with an agent

You describe, an AI agent types. Give it a Julia that answers in milliseconds.

  • JuliaDaemon.jl One warm, Revise-enabled session per project. Your agent runs jld eval instead of paying startup on every julia -e, and you can jld connect to the same session.
  • JET.jl Finds type errors and typos without running the code, so mistakes surface before the agent says "done".
  • ExplicitImports.jl Makes every name's origin explicit, which keeps agent-written code easy to review.
pkg> app add https://github.com/KristofferC/JuliaDaemon.jl

Next: julia-mcp (persistent sessions over MCP) · Runic.jl (one formatting style, no options) · TestItemRunner.jl (run one test at a time)

Taste it 
# teach your agent to use jld
jld install

# the first call starts a session
cd MyPkg
jld eval 'using MyPkg; MyPkg.foo()'

# later calls are warm, edits live
jld run test/runtests.jl

Write a package

Your scripts deserve tests, docs and a version number.

  • PkgTemplates.jl A new package with CI, docs and tests in one call.
  • Documenter.jl Docs sites from your docstrings and Markdown.
  • Aqua.jl Automatic checks for the mistakes package authors make.
pkg> add PkgTemplates Documenter Aqua

Next: JET.jl (find bugs before running) · Runic.jl (formatter) · PrecompileTools.jl

Taste it 
using PkgTemplates

t = Template(; user = "your-github-name",
               plugins = [GitHubActions(), Documenter{GitHubActions}()])
t("MyPackage")
🛳️

Ship it

Other people need to run your code without installing Julia.

  • JuliaC.jl Compile a program into a small native executable or library.
  • Pkg apps Install command-line tools written in Julia, with app add.
  • PackageCompiler.jl Custom system images and relocatable apps.
pkg> app add JuliaC

Note: JuliaC installs as an app, so juliac lands in ~/.julia/bin. Add that to your PATH.

Taste it 
# hello.jl
function (@main)(args)
    println(Core.stdout, "Hello from a native binary!")
    return 0
end

# then, in your shell:
#   juliac --output-exe hello --bundle build --trim=safe --experimental hello.jl

Didn't find yours?

There are over 12,000 more. Some places to look:

  • JuliaHub Search every registered package and its docs.
  • Package comparisons Help choosing between similar packages.
  • Ask on Discourse The "New to Julia" category is friendly and quick.

Then mix them

Julia packages work together even when their authors never planned it. That's multiple dispatch at work, and it's why a small kit goes a long way.

Write a function once…

# Newton's method, for plain numbers
function mysqrt(x)
    t = x
    for _ in 1:10
        t = (t + x / t) / 2
    end
    return t
end

…and every package can use it

julia> using Measurements, ForwardDiff

julia> mysqrt(2.0 ± 0.1)     # error bars, propagated
1.414 ± 0.035

julia> mysqrt(big"2.0")      # as many digits as you like
1.414213562373095048801688724209698078569671875376948073176679737990732478462119

julia> ForwardDiff.derivative(mysqrt, 2.0)   # an exact derivative
0.35355339059327373

Measurements.jl and ForwardDiff.jl know nothing about mysqrt, and mysqrt knows nothing about them. With CUDA.jl, mysqrt.(CUDA.rand(10^6)) runs it on a GPU too.
